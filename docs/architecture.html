Competitive Intelligence Monitoring — C4 Container Diagram

PoC architecture: Presentation → Application / Business Logic → Data Access → MongoDB

Presentation Layer

Django is responsible only for UI rendering and user interaction. It communicates with Flask through HTTP/JSON and does not access MongoDB directly.

Application / Business Logic

Flask owns the application API and monitoring logic. Layer 1 discovers candidate pages; Layer 2 monitors selected pages; social adapters collect platform-specific content.

Data Access Layer

Repository classes isolate persistence from business logic. MongoDB stores structured application data, while snapshot content is kept separately.
