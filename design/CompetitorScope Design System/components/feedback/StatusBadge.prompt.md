One-line: the pill that carries every status word in the product — use the typed wrappers where the vocabulary is fixed.

```jsx
<RunStatusBadge status="SUCCESS" />
<DiscoveryStatusBadge status="SUGGESTED" />
<StatusBadge tone="brand" icon="tag">MANUAL</StatusBadge>
```

Never use `tone="warning"` as a solid fill — solid warning is reserved for `SimulatedBadge`. Never use `favorable` decoratively.
